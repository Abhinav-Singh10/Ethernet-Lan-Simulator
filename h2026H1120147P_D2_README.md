# Ethernet LAN Simulator

Run with Node.js 24 or later.

```sh
npm install
npm run dev
```

Open the URL afterwards which will be there in the terminal . 

The defualt  example sends two frames to host B at the same time. **Press play** to watch the diagram, **Step** to advance one event, **Run all** to finish, or **Reset** to change the settings. Set the waiting slots to zero to see a copy drop.

The tests run with `npm test`.

Source files, tests, this README, and result screenshots use the submission prefix `h2026H1120147P_D2_`. For example, `simulator.ts` in the report refers to `src/h2026H1120147P_D2_simulator.ts`. Standard entry and configuration files keep their usual names so the commands above work without extra options.
